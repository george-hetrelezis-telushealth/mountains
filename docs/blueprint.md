# **App Name**: Mountain Heights

## Core Features:

- Fetch Data: Fetch the names and heights of the top 10 tallest mountains from a pre-existing source of data (such as a local JSON file)
- Display Mountain Heights: Order and display mountain names and corresponding heights, ordered by height descending.
- Visualize Data: Display mountains as proportionally sized bars, corresponding to the meter values.

## Style Guidelines:

- Primary color: Muted purple (#8E44AD) to evoke a sense of majesty and wonder.
- Background color: Very light purple (#F2E7FA), a desaturated tint of the primary color to provide a calm backdrop.
- Accent color: Teal (#008080) to draw attention to key data points, contrasting the purple tones.
- Body and headline font: 'Inter', a grotesque-style sans-serif, will ensure a modern, clean, objective appearance.
- Clean and simple layout to focus on data visualization; mountain names on the left, bars representing heights in the center, and actual height numbers on the right.
- Subtle transitions on hover over each mountain, highlighting the bar and displaying additional details.
